📋 Required Appwrite Collections

Create these in your myweb_db database:

chat_users — user_id(str), username(str), display_name(str)
chat_friends — user_a(str), user_b(str), name_a(str), name_b(str), username_a(str), username_b(str), status(str)
chat_convos — type(str), name(str), other_name(str), member_ids(str[]), created_by(str)
chat_messages — convo_id(str), sender_id(str), sender_name(str), text(str)

Set each collection's permissions to Any (read + write).
